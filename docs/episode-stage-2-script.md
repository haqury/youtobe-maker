# Этап 2: Сценарий эпизода (Секция А)

Кратко о конвейере в Студии после упрощения UI.

---

## Вверху секции

| Поле | Файл | Когда пишется |
|------|------|----------------|
| Длительность мин–макс | `episode_config.json` | ИИ-кнопки, **💾 Сохранить настройки эпизода**, перед сборкой видео |
| Кадров (0 = авто), сек/кадр | `episode_config.json` | то же; влияет на **число PROMPT** при генерации сценария, не обрезает готовый `visual_prompts.md` |
| Затухание голоса, хвост ambient (с) | `episode_config.json` | то же; читает `build_sleep_video.py` / Remotion |
| Сюжет / бриф (RU) | `plot_brief.txt` | Только при **✍️ Сгенерировать сценарий с нуля** |

Длительность и тайминг: автоматически при ИИ-кнопках или **💾 Сохранить настройки эпизода**. Перед **Собрать видео** / **Remotion** конфиг тоже сбрасывается на диск.

**✍️ Сгенерировать сценарий с нуля** — фоновая задача `generate_episode_pack.py`: outline → главы EN/RU → `visual_prompts.md` → `metadata.md` с учётом `plot_brief.txt`. Перед стартом, если уже есть `script.md`, создаётся снапшот `history/…_before_generate/`.

---

## Редактор

Вкладки: **script_ru.md**, **script.md**, **visual_prompts.md**, **metadata.md**.  
**💾 Сохранить тексты** — только ручная запись без ИИ.

После успешной фоновой задачи вкладки подтягивают файлы с диска (сброс кэша textarea).

---

## 🛠️ ИИ-переработка по источнику истины

Задача `sync_episode_pack.py`. **plot_brief не участвует.**

1. Сохраняет тексты с вкладок + длительность из config.
2. Снапшот `before_rework` (если есть сценарий).
3. Берёт **источник истины** (RU = `script_ru.md`, EN = `script.md`).
4. **Комментарий обязателен** — перерабатывает сценарий на языке истины только по комментарию. Если модель вернула почти тот же текст — задача с ошибкой.
5. Синхронизирует **второй язык** (перевод по обновлённому первичному тексту).
6. Заново генерирует `visual_prompts.md` и `metadata.md` по EN.

Прогресс — **📡**.

---

## 🕰️ История версий

Папка `episodes/…/history/YYYY-MM-DD_HH-MM-SS_<reason>/` — копии `script.md`, `script_ru.md`, `visual_prompts.md`, `metadata.md`, `plot_brief.txt`.

**⏪ Восстановить** — перед откатом текущее состояние уходит в `before_restore`.
