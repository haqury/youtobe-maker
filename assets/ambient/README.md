# Библиотека эмбиента

Сюда кладутся длинные фоновые записи без речи. Сборка хвоста берёт файлы из выбранной категории, режет их на куски по 10–25 минут, перемешивает по id эпизода и склеивает с кроссфейдом 4–6 секунд.

## Папки

| Папка | Что класть |
| --- | --- |
| `rain/` | Дождь, капли по стеклу, далёкая гроза без резких ударов |
| `fireplace/` | Огонь, треск дров, тёплый комнатный гул |
| `night_wind/` | Ночной ветер, листва, тихий воздух |
| `water/` | Ручей, волны, берег |
| корень `assets/ambient/` | Запасные файлы. Попадают только в «Случайный микс» |

Можно добавить свою папку латиницей (`forest`, `city_night`). Она появится в списке студии сама.

## Формат

- `mp3`, `wav`, `m4a`, `aac`, `ogg`, `flac`, `opus`
- лучше записи по 30–120 минут: короткие файлы всё равно склеятся, но хвост будет менее разнообразным
- без голоса, музыки с мелодией и резких щелчков в начале
- один файл на сцену, имя любое

Пустые папки сборку не ломают, пока в выбранной категории или в миксе есть хотя бы один файл.

Синтетические дорожки (не полевые записи): `python scripts/make_ambient_library.py`. Свои длинные файлы просто кладутся в ту же папку и подменяют их.
