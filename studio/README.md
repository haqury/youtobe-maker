# Studio (веб-морда) — на паузе

Streamlit-панель: бэклог, ИИ-сценарии, фоновые задачи, превью.

**Запуск (когда понадобится):** `START_WEB.bat` или  
`streamlit run studio/app.py`

**Зависимости:** всё в `scripts/` (джобы, `job_manager`, UI вызывает те же скрипты, что и CLI).
